# SKY 3.1 专项审查与修正记录

结果日期：2026-11-01。工作区版本仍为 3.1.0。本报告区分结构化草案、执行前预检、参数使用授权、显式 RUN、数值验证和实验可信度。

## 判定口径

- **已确认缺陷**：有源码、复现或运行证据；修复前证据保留在审查目录。
- **已验证通过**：有对应测试或真实运行证据，结论只适用于列出的范围。
- **待验证风险**：有合理风险或缺少环境，不写成已发生的漏洞，也不标成通过。

本轮的 100/100 指标只称为**结构化草案生成覆盖率**，不表示方程、物理机制、边界条件或 AI 建模正确率为 100%。真实 LLM 仍未连接，测试提供者只用于协议测试。

## 已确认并修正的缺陷

| 编号 | 修复前证据 | 修正 |
| --- | --- | --- |
| D1 | 多对象以扁平参数为主，不能完整表达两个块体各自的尺寸、初温及接触 | 增加对象、事实作用域、接触关系、原文绑定和接触模型选择；不支持的多对象任务保留草案，不套单块冷却 |
| D2 | 改变边界后，未变数值的旧授权仍被保留，冷却预检仍通过 | 结构变化撤销相关旧授权、使旧记录失效；改变结构的编辑不能自报已有执行器支持，需重新生成兼容方案 |
| D3 | 未配置会话凭据时可创建会话；部分读取接口也未统一受保护 | 缺少凭据时拒绝状态修改与私人数据检索/读取，只保留健康检查和纯输入预览/解析；凭据不符返回 401 |

| D5 | 固定冷却执行器可忽略额外写入的接触条件；常系数稳态扩散也会接受变系数、时变边界或分层描述 | 增加统一单位/执行器物理范围检查；明确不支持的机制拒绝该执行器，继续提供合适的草案与待选条件 |

## 实际物理验收

现有铁块方程包含**对流换热和灰体辐射**。仅对流是新增消融组，不再称为原有基准。

| 组别 | 模型 | 目的 |
| --- | --- | --- |
| A | 常物性、仅对流，辐射率设为零 | 分离辐射的贡献 |
| B | 常物性、对流及灰体辐射 | 保留原有机制的参考组 |
| C | 明确系数的线性 k(T)、Cp(T)，对流及灰体辐射 | 检查温度相关物性近似与焓守恒 |
| D | 改变换热系数及辐射率 | 检查换热参数敏感性 |
| E | 封闭二维域的瞬态扩散，余弦初态、无源、无通量 | 新的独立时间演化模型，检验真实浓度场和守恒 |

A–D 是同一热学问题的机制/参数对照，不能计成四个独立领域模型。C 的系数属于明示的数值探索假设，不是实测铁材料曲线；不据此断言比 B 更接近实验。E 是另一个受支持的物理问题，不等于任意瞬态扩散编译器。

每个热学组分别进行三套网格求解，并在细网格上收紧容差、减小最大时间步后重解；保存每次真实求解的自由度、单元数、设置和 CSV 摘要。对流与辐射热功率分别读取并积分。温度相关 Cp 的能量检查使用相应焓关系，不继续套常 Cp 能量公式。

瞬态扩散导出实际 `c(x,t)`、坐标与守恒积分；独立校验器重新计算余弦衰减解析解。首次粗网格结果因约 0.4% 的初态剖面误差未通过 0.2% 阈值；随后加密网格通过，未放宽误差限值。拒绝的运行记录也保留在审查目录中。

最大内部步长和 BDF 参数按 [COMSOL 6.3 Time API](https://doc.comsol.com/6.3/doc/com.comsol.help.comsol/comsol_api_solver.51.50.html) 设置并回读；输出采样间隔与内部时间步分别记录。

## 权限与证据边界

审批和执行绑定针对不可信 API 输入、模型生成内容、过期界面和跨凭据重放。它不声称能抵抗同一 Windows 用户或管理员直接修改整个数据库及程序。凭据轮换或旧版未绑定计划须重新 PLAN/审阅；原数据与历史结果保留，不自动认证为新版本结果。

自动化工程验收只写入独立工作区。测试用的固定凭据不被其他服务实例自动信任，也没有生产 API 的“测试批准”旁路。生产中的参数使用授权仍是经认证、绑定具体建议与版本的显式请求；该协议不是生物识别式的人类在场证明。

最终结果、数值表、命令、原始日志、文件摘要及源码快照由 审查证据目录（本机工程证据，未随源码分发） 中的 `CLOSURE_MANIFEST.json` 和 `RESULTS.md` 索引。首次探针、诊断失败与旧源码的结果不充当最后版本的通过证据。
