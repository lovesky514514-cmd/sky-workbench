# SKY Workbench 4.0 使用指南

## 准备本机环境

在「设置」检查 Runtime 和计划使用的引擎。商业求解器及许可证由用户自行提供。软件发现、连接、模型读回和实际求解各有状态。源码构建见 [BUILDING.md](../BUILDING.md)。

## 从任务到求解

1. 在「任务」描述结构、材料、边界和需要的结果。信息不足时先形成草案，逐项核对模型提出的参数、单位和假设。
2. 审阅当前计划并完成预检。修改计划后重新审核，再按提示明确授权 RUN。
3. 在「模型」查看当前尝试发布的网格检查点。若在外部 COMSOL 修改模型，先保存变更，再导入或刷新保存后的文件。
4. 在「结果」查看通过证据校验的图像和 Heat 三维温度场。在「证据」追溯 RUN、attempt 和独立物理检查。
5. 导出成果包后核对 manifest 与 SHA-256。计算终止、证据不足、提交状态未知时保留原记录，按恢复提示核对状态。
