# SKY 3.1 通用建模回归记录

本轮验证了 50 条模糊描述和 50 条明确描述。100 条均能生成可继续补全的模型草案；另外完成了 3 个真实 COMSOL 求解案例。这不表示 100 条都已获得数值解，也不表示任意自然语言都能自动求解。

## 已完成的修改

1. 引入共享建模描述 `RequestBrief`，记录领域、原始事实与文本位置、单位、冲突、排除项、候选方程、符号输入、待选条件和候选工具。规划与界面共用这些字段。
2. 模糊描述先生成参数化方案，并允许选择 AI 提议、符号参数或真实数据。缺少参数不会直接终止规划。
3. 保留服务端从原始请求提取的事实，建议不能覆盖明确尺寸、温度或材料。处理多对象不同初温与同一参数互相冲突两种情况。
4. 语义规划服务能够补充离线词表以外的领域和方程。提供者不能写入用户批准、已安装引擎或执行成功状态。
5. 补全选择经真实 API 提交，绑定建议摘要和计划版本，并记录选择范围。新生成的数值建议仍需再次审核。普通计划 JSON 编辑不能伪造选择记录。
6. 未连接语言模型时保存已审核草案和符号输入，显示服务状态，并保留补参重试入口。不会把离线规则输出标成大模型推理。
7. 执行器按物理适用范围匹配。加热、水中冷却、接触、相变、材料对比和其他物理耦合不会被自动转换成空气冷却或二维稳态基准。
8. 共用否定表达处理，“无反应、无对流”和“no reaction / without convection”等不再被旧纯扩散解析器误判为请求这些机制；实际要求反应仍保留其他建模方案。
9. 界面展示候选关系、符号输入、原始输入与候选工具，同时提供可操作的补全选项。新增代码保留简短注释，并按原有代码风格整理。

## 尚未验收的范围

1. 当前环境没有配置可用语言模型。开放式语义理解、在线检索补参和真实服务产生候选的质量，还需连接模型后验收；本轮协议测试使用明确标记的测试提供者。
2. 通用草案不等于通用数值执行器。已有执行器的适用范围仍有效，不能仅因识别出软件名称就宣称模型可运行。未定义单位契约的数值建议仍需补充单位适配。
3. MATLAB、VASP、Materials Studio 的真实求解未在本轮执行。本轮也未验证这 100 条对应的所有 LAMMPS 势/结构或数学求值任务。
4. 本轮完成源码修改、前端构建与本地回归；之前的安装包不能代表此次修改，尚未用本轮源码重新打包或上线。
