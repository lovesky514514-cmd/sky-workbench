## 未采纳的方案

1. C6 改成 `<=` 会把提前结束当完成，保持 `==`。
2. A4 在同一可编辑 JSON 内追加散列不能抵抗同用户修改；本轮选 T1 并公开边界。
3. C1 对所有体系固定平衡时长、生产时长和物性误差阈值不成立；必须指定体系、势函数、截断/尾修正、状态点及参考。当前短 LJ 算例只验执行与有限诊断，不授予物性认证。
4. B2 不对 NSW=0 单点强制离子收敛；电子收敛仍单独检查。
5. F3 不沿用“相对阈值必不为空”的错误前提；保留合理下限，增加明确无证据契约。
