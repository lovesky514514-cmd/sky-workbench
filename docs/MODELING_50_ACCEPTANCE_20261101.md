## 本轮修正与专项测试

已确认并修正：中文辐射率、冷却时长与“每 N 秒输出”的事实解析遗漏；中文余弦初态同义表述遗漏；Mathics 数值求值 N 被白名单误拒绝。数值表格仍显示为非标量结果，额外采样校验在验收报告中单独记录，未把正常退出称为科学认证。

加固指定引擎约束：指定 MATLAB 等引擎的任务不能绑定到 COMSOL 固定流程，规划与直接执行预检均检查；中文与软件名无空格、否定替代引擎有专项测试。

缺失软件的负例验证：LAMMPS/VASP/MS 的任务及握手 API 返回 409；MATLAB/Mathics 脚本 API 返回 409，不创建运行记录。real/metal 不能传给 LJ，MS 优化不能传成单点能，输入 API 返回 422。这些受控负例不使用真实 POTCAR，不启动伪求解器。

完整后端回归：**1384 passed、14 skipped**。14 项均为历史 RC 打包辅助测试，另有既有 Starlette/httpx 弃用提示。测试期间受检源码摘要不变；测试完成后仅补齐源码打包器的公开资源、构建文件、许可证及依赖声明清单，运行后端、测试及执行脚本未变。同步包解压副本的 50 条草案/API 边界复验通过，前端生产构建通过（复用本机现有依赖，有既有大分块提示）。这不是另一台干净电脑的环境认证。
