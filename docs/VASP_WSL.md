# 在工作台接入本机 VASP WSL2

在 Windows 桌面工作台打开 **VASP** 任务页。选择「发现 WSL 发行版」，再配置实际注册的 Ubuntu、VASP 的 Linux `bin` 目录、Open MPI 的启动器、MPI 进程数和授权赝势根目录。选择 `vasp_std`、`vasp_gam` 或 `vasp_ncl`。配置保存在当前项目的本机运行时数据中。项目代码和测试只包含示例值。

「测试 WSL 连接」检查 WSL2、Ubuntu、可执行权限、动态依赖、VASP 和 MPI 版本及赝势根目录的可访问性。这个操作不提交计算。当前运行范围为不含 SOC、非共线和响应计算的静态 SCF，使用自动 Gamma 或 Monkhorst-Pack 网格。选择 `vasp_gam` 时要求无偏移的 Gamma 1×1×1。选择某个二进制、握手成功和验证该物理模式是不同的事。

导入原始 `INCAR`、`POSCAR`、`KPOINTS`，或生成带明确晶格常数的 Si 草案。POSCAR 需要显式元素符号。赝势根目录按 `元素目录/POTCAR` 组织，例如 `Si/POTCAR`，通过可选映射可选择同元素的其他版本。POTCAR 在 Linux 内按 POSCAR 顺序检查 TITEL 并组装。工作台预览和日志只保存物种、适配信息和散列，Windows 交换目录与公开资产均不包含 POTCAR。

点击「预览结构与检查输入」生成十分钟有效的审核票据。审核绑定当前项目、VASP/MPI 二进制指纹、WSL 配置、输入和赝势散列及超时。修改任何一项需要重新预检。用户勾选授权并点击「开始计算」后，现有 EngineTaskManager 才写入运行记录和启动 Linux Worker。同一票据的重复请求返回同一运行。

实际 MPI 在 Ubuntu 用户的私有 Linux 任务目录运行。工作台从固定文件名单收集日志、OUTCAR、OSZICAR、CONTCAR 和可选 vasprun.xml；大文件留在本机 Linux 任务目录。取消、超时和断电后会保留账本。取消按本次 Linux 进程组和带标记的 MPI 进程回收。退出尚未确认时，可在工作台点击「核对并回收本次 Linux 任务」。未确认清理的中断任务会阻断当前项目的新 VASP WSL RUN。

## 同一 Si 算例的实机验收

可在 Windows PowerShell 核对本机注册名称和已配置二进制的版本。把占位符换成实际已授权的本机配置。

```powershell
wsl.exe --list --verbose
wsl.exe --distribution '<注册名称>' --exec '<Linux bin 目录>/vasp_std' --version
```

先在已经通过的原始算例目录中记录下列本地摘要，用来核对输入和授权赝势。只需摘要，无需发送文件原文。

```bash
sha256sum INCAR POSCAR KPOINTS POTCAR
```

在工作台选择已握手的 `vasp_std`，MPI 进程数设为 2，导入该目录的三个文本输入，预检后比较四个散列。确认 Si 两原子原胞、ENCUT 400 eV、PREC Accurate、EDIFF 1E−6 和 Gamma 4×4×4。只有用户确认后才提交 RUN。检查退出码、完整 OUTCAR/OSZICAR、电子收敛标记、最终电子迭代次数与最终 TOTEN。以用户原始结果 −10.65638172 eV 为基准。四个输入散列和 MPI 配置一致时，本次对照采用绝对差 ≤ 1×10⁻⁵ eV。该容差仅用于同一静态 Si 算例；11 次迭代是诊断对照值。即使运行记录标记为已收集，科学验收仍需核对这些证据。

Si 草案可验证输入生成和预检，未核对晶格及原文件摘要之前不能作为同一算例。结构优化、MD、非共线、VTST、桌面安装包均另行验收。
