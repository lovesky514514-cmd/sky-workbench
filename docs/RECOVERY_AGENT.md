# SKY Recovery Agent

在会话的检查器打开「故障诊断」。选择一条故障，点「开始只读诊断」。面板显示来源、分类、仍需核对的证据、反证和处理建议。可以停止当前诊断或模拟，也可以导出 JSON。导出含事件 ID、哈希和必要的运行身份，无原始请求、认证数据、完整日志或模型内容。处理网络异常时，界面会提示刷新记录。

支持纯规则工作。只有用户勾选模型辅助、已经配置模型供应商且规则证据不足时，才发送脱敏的结构化摘要。模型只能从允许的原因类型中选择候选，并引用本次登记的证据。它不获得工具、审批或科学判定权限。

## 数据与状态

- `FailureEvent` 包含来源、模板路由、方法、状态、稳定错误码、发生和接收时间、事件关联、允许的结构化事实和作用域。项目、会话、计划版本、专家 task/attempt 与科学 run/attempt 分开；未知身份留空。重复事件 ID 返回原案例，内容不符则拒绝。相似指纹只作定位，不跨尝试合并记录。
- `DiagnosticSnapshot` 记录采样时间、当前 plan/revision、计划摘要、RUN/attempt 状态和所有权匹配事实。`DiagnosisReport` 保存规则、候选、反证、缺失证据和来源。`Proposal` 记录动作、范围、风险、审批、复验方法和摘要。
- 状态由宿主推进：`DETECTED → SNAPSHOTTING → CLASSIFIED → DIAGNOSING → PROPOSED`。需要模拟时再走 `WAITING_APPROVAL → SIMULATING → VERIFYING`，根据独立复验进入 `RESOLVED` 或 `UNRESOLVED`。过期、阻断、取消、超时各有终态。重启时不会重放已登记的模拟动作。
- SQLite 沿用 SessionStore，增加故障案例、追加事件、故障库和模拟执行登记。状态及其记录在短事务内写入，并检查当前状态和版本。故障采集与原响应分离；数据库繁忙等采集失败累加固定的丢失计数。当前每个项目最多记录 5,000 个案例，每分钟最多 120 个，达到上限不删除历史。
- 故障库可保留未验证候选、复现、已验证修复、负例、拒绝和弃用。检索按项目、来源、故障签名和版本约束。规则未决时，命中已验证案例只产生候选，不能改变当前故障的权限。只有宿主能准入条目；独立观测复验证据与明确审核才可产生 `VERIFIED_FIX`。没有用模拟证据预填已验证修复。

## 权限与 409 分支

| 操作 | 权限 |
| --- | --- |
| 故障详情、导出 | 桌面认证、当前项目和会话隔离；项目级事件不归属任意会话的私有日志 |
| 诊断 | N02 宿主按需派发。仅授予当前任务的快照读取和已验证知识库检索。日志和 HTTP 正文不转成命令 |
| 提交和审批模拟 | 总控重新检查计划、当前尝试和 COMSOL 所有权，审批绑定提案摘要。会话没有 RUN 时必须确认没有活动尝试和占用，再使用会话审核事件 |
| 模拟 | 仅模拟安全状态刷新。总控确认审核、登记一次动作，独立验证器重新取快照。界面将通过显示为「模拟复验通过；实际故障仍未确认修复」 |
| 真实 RUN、参数写入、覆盖产物、释放锁、删除文件、执行任意脚本 | Recovery Agent 没有这些能力 |

计划版本或审核摘要失效时只建议刷新差异和重新审核。Bridge 被占用时只建议核对所有权。Heat 核心或场读回异常时只查已授权证据；不调用会创建临时 COMSOL 节点的场查询。参数写入或求解返回但读回失败不能推断没有副作用。提交后回执丢失为 `SOLVE_COMMIT_UNKNOWN`，禁止补发 RUN。文件已存在时保留文件并提示核验归属和哈希。未知 409 标记 `UNKNOWN`。计划、许可、资源或网络异常之间以受信信号区分。

原 FastAPI 错误状态保持不变。当前记录来源包括受桌面认证的 FastAPI 409/5xx、经异常链关联的 Java Bridge 状态/传输错误、N02 调度观察口、带运行身份的 ToolRegistry 错误、科学运行的预检/失败及明确调用的环境探针。后台轮询得到的正常降级状态不重复写入。当前快照用 SessionStore 和 RunJournal 的安全投影，不重新启动 Bridge 或采集原始模型。

## 接口

`GET /api/recovery/cases?session_id=…`、`GET /api/recovery/cases/{case_id}?session_id=…` 和同路径下的 `/export` 提供查询。以下后缀为 POST，均要求相同的会话参数：

| 后缀 | 请求 |
| --- | --- |
| `/diagnose` | `{"allow_model":false}`，重复调用返回当前记录 |
| `/submit` | 仅提交可模拟的提案 |
| `/review` | `{"decision":"approve","proposal_digest":"…"}` 或 `reject` |
| `/simulate` | 只有当前已获批准的模拟提案可以执行 |
| `/cancel` | 停止诊断或模拟，历史记录保留 |

模拟恢复的复验不改变科学运行记录。95/100 的评分都不能覆盖科学硬门槛。以下是本轮真实 COMSOL 的验收状态。每一步需要各自的证据，发现安装路径不能替代后续验证。

| --- | --- | --- | --- |

| Java 编译 | 对应版本依赖下的编译记录 | `NOT_RUN` | `NOT_RUN` |
