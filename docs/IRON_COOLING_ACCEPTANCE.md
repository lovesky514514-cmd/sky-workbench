# 三维铁块建模验收

日期：2026-10-31。原话：“我想做一个3x3x20mm的烧红的铁块，现在想分析热变化。”

原 3.1 内部候选对这句话生成空通用草案，未识别三维尺寸、材料和瞬态热过程。接口连接不能证明自然语言到模型的路径可用。本轮修复共享末尾单位、三维冷却意图、候选参数审核、专用执行器及运行阶段事件。

## 本轮测试条件

用户明确给出的事实只有 3 × 3 × 20 mm 和铁块。“烧红”的数值温度、放置环境和后续过程均不确定。本轮作为独立工程验收，使用以下候选假设；没有把自动测试批准记作真实用户逐项确认。

| 参数 | 探索值 | 状态 |
| --- | --- | --- |
| 初始温度 | 800 °C（1073.15 K） | 假设，不能由颜色精确确定 |
| 空气/等温辐射环境 | 25 °C（298.15 K） | 假设 |
| 对流换热系数 | 10 W/(m²·K) | 假设，未求解空气流动 |
| 表面发射率 | 0.8 | 假设，需按表面状态校准 |
| 导热系数/密度/比热 | 45 W/(m·K)、7870 kg/m³、650 J/(kg·K) | 未校准常数近似 |
| 输出 | 0–300 s，每 1 s 输出 | 求解器内部使用自适应步长，rtol=1e-5 |

模型为三维固体导热，六个面采用对流与灰体辐射，未建立空气流体域，未计支撑接触导热、氧化反应、温度相关材料性质及转变热容峰。因此数值验证只针对所声明的简化方程，不认证实际铁块的冷却预测。

固体满足 `rho*Cp*dT/dt = div(k*grad(T))`，边界采用进入固体的热通量 `h*(Tamb-T) + epsilon*sigma*(Tamb^4-T^4)`。符号约定和辐射形式参见 [COMSOL 热流边界](https://doc.comsol.com/6.3/doc/com.comsol.help.heat/heat_ug_modeling.06.21.html) 与 [表面对环境辐射](https://doc.comsol.com/6.3/doc/com.comsol.help.heat/heat_ug_ht_features.09.088.html)。初温、表面和材料常数由本次探索假设提供，不冒充上述文档的实测数据。

## 实际结果

在本机 COMSOL 6.3 的全新后台模型中完成，未操作桌面、浏览器、已有模型或快捷方式。冻结程序已完整走通 `原话 → 意图 → 草案 → 测试范围授权 → RUN → COMPLETED`。

- 300 s 平均温度约 **108.386 °C**，空间最低/最高约 108.248/108.455 °C。
- 实际几何读回为 0.003 × 0.003 × 0.020 m，确认六个边界面、初始温度、热流、物性和瞬态研究。
- 两级网格自由度 681、1565；全时间平均温度最大相对差约 **0.000734%**，分母为初始与环境温差。
- 体内能量变化与边界热量积分相对误差约 **0.00845%**。
- Biot 上界估算约 0.00135；与独立 RK4 集总热容参考的最大差约 **0.0438%**，同样按初始温差归一。RK4 另通过无辐射时的指数解析解测试。
- 原始 MPH、PNG、CSV、验证 JSON、工作进程日志、模型卡与冻结程序 SHA-256 全部保留。

原始三维 PNG 使用自动拉伸色阶，300 s 时空间温差约 0.207 K；颜色不代表可见光“烧红”程度。定量范围以 CSV、验证报告和温度曲线为准。

数值检查曾拦截默认初始化下约 0.05 K 的初始超调；本轮收紧时间求解容差并保留指定初场后通过。运行状态事件缺失造成的完成状态失败也已修复，未通过的中间候选不作为试用交付。
