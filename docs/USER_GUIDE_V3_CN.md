# SKY Workbench 3.1 使用帮助

工作台区分草案、预检、参数使用授权、显式 RUN 与实际求解。检测到软件、命令执行成功、模型状态已验证、科学验证通过是独立状态。

## 开始使用

1. **检查环境**：首次引导或设置中的重新扫描会逐项显示 Runtime、COMSOL、其他软件与模型服务状态。发现安装入口不等于已经连接模型。
2. **配置 AI**：源码运行在设置中选择服务，填写精确模型 ID 与自己的 API Key，再主动测试连接。3.1 安装包对全新配置可默认选择 DeepSeek，已有配置保留。界面输入的 Key 只在当前 Runtime 内存中使用，重启后需重填；不要将 Key 写入任务、脚本、截图或提交仓库。
3. **输入研究目标**：既支持明确条件，也支持不完整描述。例如：“我想做一个3x3x20mm的烧红的铁块，现在想分析热变化。”
4. **审核草案**：PLAN 先保留用户已知事实，再提出带单位、理由和适用条件的候选参数与建模选择。可接受、修改或要求重新建议；假设不会因此变成实测数据。
5. **预检与 RUN**：审核绑定当前计划内容与修订。修改计划后重新审核；预检通过仍不会自动求解，必须显式 RUN。
6. **核对结果**：检查当前运行的模型读回、求解诊断、图像、曲线、文件哈希和数值检查。旧项目图像、历史审批或文件存在不能认证当前运行。

## 建模工作区

默认流程围绕模型草案、参数审核和结果图像展开。高级代码编辑用于用户主动检查/编辑脚本，语法着色不等于完整 IDE、语言服务器或科学正确性。代码输出也不自动成为已验证的 COMSOL 证据。

铁块的“烧红”没有唯一数值温度。初温、环境温度、热物性、对流换热系数、辐射率和时长均需审核。现有冷却模型包含对流与灰体辐射；恒定材料属性、无支撑接触等假设不能替代实验标定。

复杂或当前无受支持执行器的任务仍可形成有用草案，显示建模步骤、候选引擎、符号参数与待解决问题；不能套用不匹配的基准后显示求解成功。各引擎范围见[兼容说明](PROVIDER_AND_SIMULATOR_COMPATIBILITY.md)。

## COMSOL 与 MPH

用户需自行安装并合法使用对应 COMSOL 版本及模块。多版本安装可在设置中指定根目录，切换后需重新确认 API、实时模型读回与工作流兼容性。

导入 MPH 保留原件并创建工作台副本，预览不代表已成功修改。当前没有适用于任意 MPH 的通用自动修改流程；后续操作必须属于受支持范围，有可靠对象身份和明确授权。

运行控制按当前执行器能力提供。暂停要等待安全点和状态确认；停止当前 attempt 不表示可直接恢复。新 attempt 必须生成自己的运行证据。

## 多引擎与数学工作区

- COMSOL 的受支持科学工作流、MATLAB/VASP/Materials Studio 的受限接口、LAMMPS 原子模拟任务和 Mathics3 数学计算分别管理，不共享一个“已验证”标记。
- 缺少商业软件时可查看/修改草案与受支持输入，但不能启动真实求解或伪报握手成功。本轮 MATLAB、VASP、Materials Studio 的实算尚未验证。
- Mathics3 需要独立 Python 环境，将 `SKY_MATHICS_PYTHON` 指向其 `python.exe` 后重启工作台。每次求值由独立进程执行，表达式先通过受限输入检查；这不是 OS 级权限沙箱。数学结果不等于材料模型认证。
- Python/MATLAB 的主动脚本入口与科学执行分开，按界面明确确认后运行。仅回收这次工作台创建的进程树；需要长期保留的导出图像与文件请主动保存。
- 商业 Wolfram/Mathematica 程序入口已移除，数学工作区保留 Mathics3。

## 项目迁移与排查

源码同步和项目迁移分别进行。使用项目导出/导入迁移可移植内容；新电脑重新配置软件路径、授权和云服务 Key，并重新审核计划。不要复制会话令牌或把旧机器的审批当成新执行授权。
