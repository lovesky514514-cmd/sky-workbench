# SKY Workbench V3 使用帮助

本页对应 3.0 源码。工作台把自然语言计划、仿真软件操作与科学证据分开处理。**检测到软件、命令执行成功、模型状态已验证、科学验证通过**是不同状态。

## 五分钟开始使用

1. **检查环境**：首次打开时按引导查看 Scientific Runtime、COMSOL 和其他软件状态。以后可在「设置 → 常规 → 重新扫描」再次检查。扫描只找安装入口，不打开项目文件，也不消耗仿真许可证。
2. **选择 AI**：「设置 → AI 提供商 → 云端 API」选择 DeepSeek、Kimi 或豆包，填写自己的模型 ID 和 API Key，再点「测试连接」。其他服务折叠在「其他服务」。若使用本地 Ollama，先自行启动服务并确认模型存在。**不要把 API Key 写进任务描述。**密钥不会从设置中回显；Runtime 重启后可能需要重新输入。
3. **描述问题**：在「任务」页输入几何尺寸及单位、材料、物理场、边界条件和希望得到的结果，点「创建科学建模计划」。例如：“二维矩形 10 mm × 5 mm，铝，左边界 373 K、右边界 293 K、上下绝热，求稳态温度场”。这只是输入示例，不能代替验证。
4. **审查再运行**：展开计划，逐一检查参数、单位、材料来源、边界与警告。确认后才运行。运行中可暂停、人工修改或紧急停止；修改后需要重新读回和验证，不能沿用旧证据。
5. **看模型与结果**：「模型 → COMSOL 模型」在当前运行导出并核验图片后展示 COMSOL 原生图像，旁边保留结构化读回；尚无图像时明确显示不可用。「结果」页只显示绑定当前 run/attempt 且通过完整性检查的产物；「证据」页查看命令、模型状态、科学检查及证据契约。

## 导入已有 MPH

在「任务 → 导入的 MPH」拖入或选择文件。工作台把文件复制到自己的导入区，并请求预览；原文件保留在原处。预览不表示模型已成功修改。后续修改必须有真实 COMSOL 读回、明确的人工确认和新一轮证据。若 Bridge 不可用，先保留副本，检查 COMSOL 安装与许可，不要把预览当作已验证结果。

## 多版本 COMSOL

默认自动发现安装。多版本电脑可在「设置 → 常规 → COMSOL 安装目录」指定目标版本的安装根目录。首页显示检测到的版本；“Bridge 未验证”说明尚无实时连接证据。更换版本后，需要重新确认该版本的 Java API、模型读回与目标工作流；6.3 的历史结果不能认证 6.2、6.4 或其他版本。

## 多语言代码工作区

| 软件 | 当前可用 | 当前不可宣称 |
| --- | --- | --- |
| COMSOL | 安装检测；已有 Java Bridge、支持的计划与读回/验证路径 | 未经当前运行读回及科学检查的成功 |
| Python | 代码编辑、草稿导出；找到独立本机解释器时可主动运行脚本 | 内置科学 Runtime 不是任意代码沙箱；脚本输出不等于科学验证 |
| Mathics3 | 可选的独立本地内核；主动运行 `.wl`/`.wls` 表达式、查看文本与 LaTeX 源码 | 不是 Wolfram Engine，也不是安全沙箱；不自动执行 Agent 指令或认证结果 |
| MATLAB | 安装检测、本机固定表达式握手；找到 MATLAB 时可主动运行 `.m` 脚本 | MATLAB 模型同步、自然语言建模或科学认证 |
| Wolfram / Mathematica | 找到 WolframScript 时可尝试本地内核运行 `.wl` 脚本 | Notebook/符号表达式读回、自然语言建模或科学认证 |
| Materials Studio | 安装入口检测、MaterialsScript 草稿编辑及导出 | 尚无可信的脚本执行或模型读回接口 |

入口是「模型」页的独立软件标签。「设置 → 常规」可查看安装状态。代码编辑区使用 VS Code 系的 Monaco 编辑器内核，提供语法着色，但**不包含完整 VS Code 扩展系统或语言服务器**。草稿保存在本机当前任务下，也可下载为 `.py`、`.m`、`.wl` 或 `.pl`。

### 运行与查看导出结果

1. 在对应软件标签编辑脚本。程序只检测本机解释器，不会下载 Python、MATLAB、Wolfram 或许可证。
2. 仔细检查代码后勾选「我已检查此脚本并同意本地执行」，再点击「运行脚本」。脚本以当前 Windows 用户权限运行，**不是安全沙箱**；不要运行不可信代码，也不要把 API Key 写入脚本。
3. 运行最长 120 秒，文本输出有大小上限。点击「停止脚本」只回收这次 Workbench 创建的进程树。脚本在其临时工作目录直接导出的 PNG、JPG、WebP 会自动列出，可翻页并保存；也可手动选择本地图像预览。
4. 草稿、文本输出与图像都不进入 COMSOL Model Card 或科学认证。临时输出随 Runtime 关闭而清理，需长期保留时请主动保存图片。

### 可选 Math Workspace

Mathics3 不随当前安装包分发。先在独立 Python 环境安装你已审查并有权使用的 Mathics3，再把系统环境变量 `SKY_MATHICS_PYTHON` 指向该环境的 `python.exe`，重新启动 Workbench。进入「模型 → Mathics3」，状态显示“独立 Mathics3 内核可用”后，可打开 `.wl`/`.wls` 草稿或直接编辑，审查代码并勾选确认后运行。每次运行使用新的内核进程，变量不会跨运行保留；点击停止只回收本次 Workbench 创建的进程树。结果优先以受限 MathML 元素排版；不支持的公式回退显示 LaTeX 源码。

Mathics 表达式可能访问当前用户的文件或网络。此功能只供用户主动运行可信代码，不会注册为 Agent 的自动执行工具；当前没有操作系统级权限隔离。输出固定标为未认证，不能替代 COMSOL 求解、模型读回或科学证据。未检测到独立 Mathics 环境时只保留编辑与导出，不会回退到 Wolfram 或内置科学 Runtime。

当前代码工作区不再要求每次使用 Windows 共享选择器。它接收用户脚本生成的文件，不会从其他软件窗口截图或读取其模型对象；没有导出文件时也不会伪造画面。

官方接口提供了后续接入的技术路线：MATLAB 可通过 [MATLAB Engine API for Python](https://www.mathworks.com/help/matlab/matlab-engine-for-python.html) 调用，Wolfram 可通过 [WolframScript 本地内核](https://reference.wolfram.com/language/ref/program/wolframscript.html.en) 或 [WSTP](https://reference.wolfram.com/language/tutorial/FilesStreamsAndExternalOperations) 交换结构化数据，Materials Studio 的部分功能可经 [MaterialsScript API](https://www.3ds.com/assets/invest/2023-10/biovia-materials-studio-overview.pdf) 自动化。各接口仍需对应安装、版本、许可、对象映射、取消与科学验收；这些不是 V3 已有能力。

### 为什么代码运行不等于模型同步？

脚本退出码和导出图像只能说明本地脚本产生了输出，无法可靠证明材料参数、边界选择、对象 ID、求解收敛或物理正确性。直接抓取窗口同样不能得到这些结构化证据。当前运行通道与 COMSOL 科学执行互相隔离。

真正同步到模型树，需要为每个软件分别实现：受控连接、结构化读回、稳定对象身份、单位与参数映射、修改审批、取消/崩溃恢复、产物来源与物理检查。COMSOL 的 Java Bridge 不能原样替代其他供应商的接口。

## 常见问题

| 现象 | 怎么处理 |
| --- | --- |
| 找到了 COMSOL，但显示 Bridge 未验证 | 检查指定的安装版本、有效许可和 Java Bridge 日志；只检测到安装不能直接 RUN。 |
| Ollama 程序已安装，但服务不可用或出现 HTTP 400 | 在「设置 → AI 提供商」检查本地服务与模型 ID；也可改选云端 API。不要把“已安装”当成“模型可推理”。 |
| 云端 API 已配置，但显示未验证 | 点「测试连接」进行一次真实请求；核对模型 ID、账户权限及网络。测试可能消耗供应商额度。 |
| 切到新任务后没有结果 | 这是正常的身份隔离；旧任务的图像或科学结论不能用于新任务。 |
| 导入 MPH 后不能直接自动修改 | 先取得真实模型读回，核对受影响对象，再人工确认；没有可靠对象身份时必须保持不可用。 |
| 历史记录显示中断或不完整 | 保留原数据库备份，打开诊断日志；不完整记录不得重新标为已验证。 |
| Wolfram 已检测到但脚本失败 | 检查本机 Wolfram Engine/Mathematica 许可；仅安装 WolframScript 不代表本地内核已授权。 |
| MATLAB 或 Python 的运行按钮不可用 | 检查目标软件和独立解释器是否安装在当前用户可访问的路径；内置科学 Runtime 不作为通用脚本解释器。 |
| Mathics3 显示内核未就绪 | 检查独立环境中的 `mathics.session` 能否导入，以及 `SKY_MATHICS_PYTHON` 是否指向该环境的 `python.exe`；修改后重新启动 Workbench。 |

右上角「••• → 帮助」提供简明操作提示；「••• → 打开日志」查看诊断。日志可能包含技术路径，分享前请检查并脱敏。
