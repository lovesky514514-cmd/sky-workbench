# 换电脑同步与接口复验（3.1）

## 获取源码

此仓库同步 3.1 源码、测试、锁定输入和构建脚本。克隆后检查当前提交及 README、`frontend/package.json`、`frontend/src-tauri/Cargo.toml` 中的产品版本；历史标签仍指向对应历史版本。

```powershell
git clone https://github.com/lovesky514514-cmd/sky-workbench.git
cd sky-workbench
git log -1 --oneline
```

已有开发目录先保存自己的改动，再使用正常的 Git 合并流程更新；不要用强制重置覆盖本机项目或未提交修改。

## 项目和环境分别迁移

通过工作台项目导出/导入迁移可移植内容。软件绝对路径、授权、云服务 Key 和连接设置在目标电脑重新配置；安装包不提供商业求解器。

旧审批、会话令牌和历史运行记录不构成目标电脑的新一次求解授权。修改计划或执行环境后重新审核并显式 RUN，当前结果需要自己的读回、数值与证据检查。

## 复验顺序

1. 扫描 Runtime 和所需软件，确认实际版本、安装与许可；没有的软件保持不可用，不计为成功。
2. 对选定 AI 服务运行真实连接/能力测试，确认精确模型 ID。
3. 用小型、明确条件的受支持案例审核后 RUN，检查模型、数值与文件证据。
4. 再使用模糊描述审核 AI 候选参数，确认没有自动执行或把假设当成事实。
5. 分别测试需要的引擎、工作流、取消/退出、项目导入、重启和升级。

无软件时仍可进行结构化草案与输入契约检查；接口检测或输入导出不等于真实求解。当前实算范围见 [VALIDATION_3.1.md](VALIDATION_3.1.md)。
